# notary-platform-prototype-marketing-business-course
Web-based prototype for a mobile notary service in California.

A web-based prototype for a mobile notary service in California, designed to improve accessibility, transparency, and client-notary connections. Developed as a course project demonstrating problem-solving and UX design.

## Technologies Used
- HTML5, CSS3, JavaScript
- Figma (mockups and wireframes)
- Canva (branding)
- GitHub Pages (prototype deployment)

## Features
- Client registration and service request form
- Notary profiles with availability
- Booking calendar and appointment management
- Transparent pricing display

## Installation / Usage
1. Clone the repository:
https://github.com/valentinamaffeisjcc/notary-platform-prototype.git
2. Open `index.html` in a browser
3. Explore the prototype pages and booking simulation
